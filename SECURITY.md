# Security and Privacy

## Design

Missing Money Method is a public informational application designed to minimize the amount of user data handled by the application itself.

The application does not require user registration and should not request or store Social Security numbers, claim documents, banking information, government IDs, or other sensitive claim data.

Users should submit claim information only through the appropriate official government or state unclaimed-property service.

## Analytics

The production site uses Vercel Web Analytics for basic traffic measurement.

## Reporting a Security Issue

If a security or privacy issue is discovered, do not publish sensitive exploit details or user information in a public GitHub issue. Contact the project owner privately through an established Creignificent LLC or Tc.CREIG contact channel.

## Security Principle

Collect the minimum data necessary and direct sensitive transactions to the authoritative government service.
